# Alpha 与 Beta 的分工

面向心理学本科生的论文精读手册，中英双语。

围绕 Di, Y., An, X., & Li, H.-H. (2026). *Distinct oscillatory neural rhythms support
representational precision and confidence in working memory.* **Current Biology**, 36, 1–10.
<https://doi.org/10.1016/j.cub.2026.08.041>

## 内容

14 章，按原文论证顺序编排：论文速览 → 背景六概念 → 实验范式 → 方法工具箱 →
三条结果线（alpha 内容 / beta 标量信心 / 时间进程与皮层来源）→ 控制分析 → 讨论 →
局限与批判 → 术语表 → 自测 → 附录。

全部内容依据原文正文、图注与 STAR Methods 编写。所有统计数字均为原文报告值；
无法从原文核实数值的图示已在图注中标明为**示意图**，原文未报告的数字不臆造。

## 使用

单文件 `index.html`，无构建步骤、无外部依赖（仅一个 Google Fonts 外链，断网时回落到系统字体）。

- 直接在浏览器打开即可，无需登录
- 右上角切换中英文，选择记在 `localStorage`
- 桌面端左侧有章节导航；手机端为单栏
